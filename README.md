# LumiFrame AMD 채널 업데이트

기존 **LumiFrame Windows 통합 앱의 AMD 채널**을 위한 배포 저장소입니다. 별도 앱을 설치하는 방식이 아닙니다.

AMD 담당자는 개발 저장소에서 AMD 코드를 빌드·검증한 뒤 이 저장소에 AMD 채널을 직접 배포합니다. 통합 앱과 NVIDIA의 공식 배포 저장소는 별도로 관리됩니다. 이 저장소의 권한은 그 저장소의 수정·배포 권한을 주지 않습니다.

- `updates/amd.json`: AMD 담당자가 게시한 현재 채널 버전과 다운로드 SHA256
- Releases: AMD 채널 ZIP과 검증 보고서
- 사용자의 설치 대상: `runtimes/amd/<version>` 및 AMD 버전 포인터
- NVIDIA 채널, 최상위 공통 실행기, 사용자 설정과 이전 버전은 유지

AMD 업데이트 기능이 포함된 앱에서 설정의 **AMD 채널 업데이트 확인**을 사용합니다. 기존 230 설치본에는 이 새 버튼이 없으므로 기능 추가 패키지를 한 번 적용해야 합니다.

[AMD 업데이트 기능 추가 v1](https://github.com/ETONOTE/LumiFrame-AMD-Releases/releases/tag/amd-update-support-v1)은 최초 적용·복구와 기존 파일 보존 검사를 통과한 사전배포입니다. AMD 담당자의 실기기 인수 확인을 위한 패키지이며 일반 업데이트 피드와 통합 앱 Latest에는 반영하지 않았습니다. ZIP 안 README.txt의 설치 절차를 따르세요.

초기 피드는 이미 공개된 230 통합 설치본의 **기존 AMD218**을 가리킵니다. 새 AMD 성능 개선이나 새 실기기 검증을 뜻하지 않습니다. 새로운 AMD 버전의 화질·속도·프레임·오디오 및 실제 AMD GPU 검증은 AMD 담당자가 배포 전에 수행합니다.

소유자의 매회 수동 승인이나 NVIDIA 재배포 없이 AMD 채널만 업데이트할 수 있도록 개발·배포 권한을 분리합니다. 아직 담당자 초대 전입니다.
